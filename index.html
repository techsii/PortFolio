Featured Project

Case Study

TutorNear

Location-Based Tutor Discovery Platform

Problem

Students often struggle to find qualified tutors nearby and compare subjects, fees, and availability efficiently.

Solution

TutorNear connects students with nearby tutors using geolocation, smart recommendations, and interactive maps, making tutor discovery faster and more convenient.

Technologies Used

React.js Vite Firebase Authentication Firebase Realtime Database React Leaflet MapTiler Tailwind CSS Node.js Express.js Cloudinary

Key Features

  • Location-based tutor search using GPS
  • Distance calculation using Haversine Formula
  • Interactive map with tutor markers
  • Subject and fee filtering
  • Smart tutor recommendations
  • Tutor profile management
  • Firebase Authentication
  • Real-time tutor availability tracking

Challenges Solved

Implemented geolocation-based tutor matching, accurate distance calculations using the Haversine Formula, optimized Firebase queries for faster search results, integrated interactive maps, and created a scalable recommendation system.

Impact

Help students discover nearby tutors quickly, reduce search time, improve tutor visibility, and provide a seamless platform for connecting students with qualified tutors.
