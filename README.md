# Neel Bhattacharjee - Professional Portfolio

A modern, premium, fully responsive full-stack developer portfolio website built with HTML, CSS, and JavaScript.

## 🚀 Features

### 🎨 Design & Aesthetics
- **Modern Dark Theme**: Deep navy/charcoal background with subtle gradient accents
- **Glassmorphism Effects**: Beautiful frosted glass components throughout
- **Smooth Animations**: CSS transitions and keyframe animations
- **Micro-interactions**: Hover effects, loading animations, and particle backgrounds
- **Professional Typography**: Clean sans-serif fonts (Inter & JetBrains Mono)

### 📱 Responsive Design
- **Mobile-First Approach**: Optimized for all screen sizes
- **Flexible Grid Layout**: CSS Grid and Flexbox for perfect layouts
- **Touch-Friendly**: Optimized for mobile interactions
- **Progressive Enhancement**: Works on all modern browsers

### ⚡ Performance & SEO
- **Fast Loading**: Optimized CSS and JavaScript
- **SEO Optimized**: Proper meta tags and semantic HTML
- **Accessibility**: ARIA labels and keyboard navigation
- **Progressive Web App Ready**: Can be enhanced with PWA features

### 🛠️ Technical Features

#### Navigation
- Sticky navbar with scroll effects
- Mobile hamburger menu
- Smooth scrolling to sections
- Active link highlighting
- Scroll progress indicator

#### Interactive Elements
- **Theme Toggle**: Dark/Light mode switch with localStorage
- **Contact Form**: EmailJS integration with validation
- **Scroll Animations**: Intersection Observer API
- **Particle Background**: Canvas-based animated particles
- **Loading Animation**: Smooth page load experience

#### Sections
1. **Hero Section**: Animated introduction with professional photo
2. **About Section**: Professional summary with statistics
3. **Featured Project**: Case study style project showcase
4. **Projects Section**: Grid layout with hover effects
5. **Skills Section**: Animated progress bars and tech icons
6. **Experience Section**: Timeline layout
7. **Contact Section**: Modern glassmorphism form
8. **Footer**: Clean and professional

## 🚀 Getting Started

### Local Development
1. Clone or download the portfolio files
2. Open `index.html` in your browser
3. No build tools required - it's vanilla HTML/CSS/JS!

### Customization

#### Colors & Theme
Edit CSS custom properties in `styles.css`:
```css
:root {
    --bg-color: #0f1115;
    --accent-primary: #667eea;
    --accent-tertiary: #00f2fe;
    /* ... more variables */
}
```

#### Content
Update content in `index.html`:
- Replace project information
- Update skills and percentages
- Modify contact details
- Add your own projects

#### Images
Replace placeholder images:
- Hero section profile image
- Project screenshots
- Background images

## 🔧 Contact Form Setup

The contact form uses EmailJS for sending emails. To set it up:

1. Create an EmailJS account
2. Set up an email service and template
3. Update the `service_i6oxght` and `template_rfs0a1u` IDs in `script.js`
4. Update the `emailjs.init()` with your public key
